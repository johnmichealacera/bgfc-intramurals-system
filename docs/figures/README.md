### Inserting into Word

1. Open the manuscript in Microsoft Word.
2. Place the cursor at the figure location (Chapter 3 for Figure 1; Chapter 4 for Figure 2).
3. **Insert → Pictures → This Device** → select the matching `.png`.
4. Set width to the full text column (~6.5 inches). Height will follow.
5. Add the caption under the image.
